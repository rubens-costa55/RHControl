# RH Control

### Sistema de Gestão de Recursos Humanos e Departamento Pessoal

Sistema desktop desenvolvido para auxiliar no gerenciamento de funcionários, jornadas, férias, folha de pagamento e controle de acesso.

---

## 📌 Sobre o projeto

O **RH Control** é uma aplicação desktop desenvolvida em C# com Windows Forms, criada para centralizar e facilitar rotinas relacionadas à gestão de funcionários e processos de Recursos Humanos.

O projeto foi desenvolvido como uma aplicação prática, com foco em organização, segurança, facilidade de uso e controle das informações.

---

## ✨ Funcionalidades

- 👥 Cadastro e gerenciamento de funcionários
- 🔎 Consulta e pesquisa de funcionários
- 📅 Controle de jornada
- 🏖️ Controle de férias
- 💰 Folha de pagamento
- 💳 Registro de pagamentos
- 🔐 Controle de acesso por perfil
- 👤 Perfis de Administrador e Usuário
- 🔑 Recuperação de senha
- ⚙️ Configurações do sistema
- 🗄️ Banco de dados SQLite
- 📊 Dashboard para acompanhamento das informações

---

## 🔒 Controle de acesso

O sistema possui diferentes níveis de acesso:

**Administrador**
- Acesso completo às funcionalidades administrativas.
- Gerenciamento de funcionários.
- Configurações do sistema.
- Operações de folha e demais recursos conforme as permissões.

**Usuário**
- Acesso às funcionalidades permitidas pelo perfil.
- Consulta de informações.
- Operações disponíveis de acordo com as permissões configuradas.

---

## 🗄️ Banco de dados

O sistema utiliza **SQLite** para armazenamento das informações.

A estrutura do banco é inicializada automaticamente pela aplicação, facilitando a utilização em novos ambientes.
